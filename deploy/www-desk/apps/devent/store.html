      Документация

      Один API. Меняется только base URL и способ входа.

      Swagger
      Base URL Auth Сканер Заявки AUTO_INVENTORY

      Base URL

      Пути ручек одинаковые. Отличается только префикс хоста.

      BaseПример warehouses
      Prod https://devent.svitex.ru GET /api/v1/wms/warehouses
      Sandbox https://devent.svitex.ru/sandbox GET /sandbox/api/v1/wms/warehouses

      Ниже — путь после base. Для песочницы добавьте префикс /sandbox.

      Интерактив: /swagger · sandbox: /sandbox/swagger

      Auth

      • Prod · сотрудник — cookie wb_admin_session после POST /api/admin/login
      • Prod · админ — POST /api/admin/login-key + ADMIN_ACCESS_KEY
      • Sandbox — X-API-Key: <SANDBOX_API_KEY>

      Сканер · пик → набрано

      POST /api/v1/wms/{order_id}/pick/{warehouse_id}
Content-Type: application/json

{
  "items": [
    { "barcode": "4600000000001", "quantity": 1 },
    { "product_id": 42, "quantity": 2 }
  ]
}

      Пик увеличивает наборку, физический остаток не меняет. Id: product_id / barcode / артикул.

      Заявки · клиенты

      • GET/POST /clients · в заявке только client_id
      • GET/POST /orders · DELETE|PATCH …/items/{id}
      • POST /orders/{id}/complete · /cancel

      AUTO_INVENTORY

      Env: WMS_AUTO_INVENTORY=1 (по умолчанию вкл.)

      При расходе/пике, если свободно < нужно — выравнивание, затем операция.
