Как пользоваться
  1. Обновить с WB — подтягивает актуальные остатки (это не «новые» товары, а полная перезапись базы).
  2. Если цифры не изменились — на Wildberries данные те же самые.
  3. Включите только с остатком, чтобы скрыть нулевые строки. Артикул подтягивается из statistics API по nmId.
