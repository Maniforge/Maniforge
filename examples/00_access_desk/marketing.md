# Access Desk — пропуска и временный доступ

**Кейс:** вы развернули Maniforge у себя. Нужен не «ещё один фреймворк», а рабочий модуль: выдавать подрядчикам и гостям временные пропуска на склад / офис / площадку — с ролями, аудитом и API без написания бэкенда с нуля.

## Для кого

- Операционный руководитель, которому «нужно вчера»
- Интегратор, который подключает турникет, Telegram-бот или 1С
- Разработчик, который хочет увидеть Maniforge «в деле» за один вечер

## Что получает бизнес

| Без Maniforge | С Access Desk на Maniforge |
|---|---|
| Таблицаца в Excel + переписка в мессенджере | Единый реестр пропусков в tenant / project |
| Отдельный микросервис «пропусков» 2–4 недели | Manifest + REST за минуты |
| Свои login / роли / аудит | Готовый **RBAC** платформы |
| Сложно отдать подрядчику API | OpenAPI и Bearer-токен из коробки |

## Что делает модуль

1. **Вход** через Maniforge RBAC (сессия, tenant, project).
2. **Сущность `access_pass`** через Manifest Engine: гость, зона, срок, статус.
3. **CRUD по API**: выдать, продлить, отозвать, список активных.
4. **Мини-UI** в `files/ui/` — логин и выдача пропуска в браузере.

## Ценность одной фразой

> Авторизация и мультитенантность уже в платформе. Access Desk — только ваша бизнес-сущность поверх неё.
