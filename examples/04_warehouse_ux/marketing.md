# Warehouse UX Suite — 10 экранов складского учёта

Набор **UI/UX-сценариев** складского учёта на self-hosted Maniforge: приёмка → размещение → остатки → перемещение → отгрузка → инвентаризация → партии → резервы → локации → ТСД.

## 10 экранов

| # | Экран | Задача пользователя |
|---|--------|---------------------|
| 01 | **Обзор склада** | KPI: позиции, черновики, алерты по срокам |
| 02 | **Приёмка** | Зафиксировать входящую поставку |
| 03 | **Размещение** | Задачи putaway с RCV в ячейку |
| 04 | **Остатки** | Балансы SKU × ячейка |
| 05 | **Перемещение** | Внутренний трансфер между ячейками |
| 06 | **Отгрузка** | Подбор / отгрузка по заказу |
| 07 | **Инвентаризация** | Книга vs факт, расхождения |
| 08 | **Партии / FEFO** | Сроки годности, карантин |
| 09 | **Резервы** | Удержание под заказ |
| 10 | **ТСД / сканер** | Мобильный контур штрихкода |

## Для кого

Кладовщик, старший смены, операционный директор, интегратор WMS.

## Ценность

Один tenant Maniforge — десять рабочих экранов без отдельного WMS-фреймворка. Auth уже в RBAC; сущности — Manifest Engine.
