# HR Desk — кадровый контур

**Кейс для HR:** вакансии и заявки на отпуск поверх Maniforge — без внедрения тяжёлой HCM.

## Для кого

- HR-менеджер / офис-менеджер
- Руководитель подразделения
- Интегратор (бот согласований, 1С ЗУП — через API)

## Суть

| Сущность | Смысл |
|----------|--------|
| `hr_vacancy` | Вакансия: должность, отдел, статус |
| `hr_leave_request` | Отпуск / больничный: сотрудник, даты, статус согласования |

Связка с оргструктурой (`01_org_structure`) — по желанию через `unit_code`.
