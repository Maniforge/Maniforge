# Elections Desk — выборы и участки

**Кейс для гос / муниципальной структуры:** реестр избирательной кампании — событие выборов, участки (УИК), кандидаты. Без отдельной ИС «на полгода».

## Для кого

- Аппарат комиссии / IT муниципалитета
- Интегратор портала открытых данных
- Подрядчик, которому нужен API справочников под отчётность

## Суть

| Сущность | Смысл |
|----------|--------|
| `election_event` | Кампания: уровень, дата, статус |
| `polling_station` | Участок (УИК): адрес, привязка к кампании |
| `candidacy` | Кандидат / список: округ, партия, статус |

Auth и tenant — Maniforge RBAC. Данные — Manifest Engine.
