# Org Structure — оргструктура компании

**Кейс:** вы развернули Maniforge. Нужен реестр бизнес-структуры: юрлицо → подразделения → сотрудники. Не Excel и не отдельная HRM «на год».

## Для кого

- Собственник / операционный директор: «кто кому подчиняется и где сидит»
- HR / офис-менеджер: быстрый учёт без тяжёлой ERP
- Интегратор: отдать оргструктуру в 1С, Bitrix, Telegram-бот через API

## Что получает бизнес

| Без Maniforge | С Org Structure на Maniforge |
|---|---|
| Таблицы в Google Sheets | Сущности в tenant / project с API |
| Разные «справочники» в каждой системе | Один source of truth |
| Свой микросервис справочников | Manifest Engine за минуты |
| Сложный доступ | Готовый RBAC платформы |

## Что делает модуль

1. **`org_unit`** — компания, дивизион, отдел, команда (`parent_code` для дерева).
2. **`org_employee`** — сотрудник, привязка к `unit_code`, должность, статус.
3. Скрипты seed: типовая структура «ООО → Коммерция / Операции / Финансы».
4. Мини-UI: дерево подразделений + список людей.

## Ценность одной фразой

> Оргструктура — справочник на API. Auth и мультитенантность уже в Maniforge; вы описываете только поля бизнеса.
