# ADR-0001: Go — основной runtime, PHP — референс

- **Статус:** accepted
- **Дата:** 2026-06-08

## Контекст

Платформа выросла из PHP-монолита (`app/Maniforge/*`). Нужен основной рантайм для масштабирования и Manifest Engine, без потери проверенных контрактов.

## Решение

- **Go (Fiber)** — основной язык продакшн-разработки: `cmd/`, `internal/`, PostgreSQL.
- **PHP** — сохранён как референс: journey-тесты, паритет API, legacy-ноды до cutover.
- Поведение Go должно совпадать с PHP journey до явного ADR об изменении контракта.

## Последствия

- Две БД до cutover (PG для Go, MySQL для PHP-референса).
- Дублирование логики временно допустимо; расхождение — баг Go-контура.

## Альтернативы (отклонённые)

- Полный rewrite без PHP-референса — высокий риск регрессии.
- PHP как основной навсегда — не масштабирует Manifest Engine на Go.
