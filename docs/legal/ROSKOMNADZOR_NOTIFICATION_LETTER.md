- `[иные ФЗ, если применимо]`.

### 6. Перечень действий с персональными данными

- Сбор, запись, систематизация, накопление, хранение, уточнение (обновление, изменение);
- Извлечение, использование, передача (предоставление, доступ) — в объёме, необходимом для оказания услуги;
- Обезличивание, блокирование, удаление, уничтожение — по запросу субъекта и при достижении целей обработки;
- `[трансграничная передача — если есть, см. раздел 9]`.
