---

## Проекты

### 🧩 MANIFORGE — low-code платформа *(pet / R&D)*

API-first платформа для быстрого создания бизнес-приложений.

Пользователь описывает сущность (Manifest) → платформа генерирует **REST API**, **OpenAPI** и базовый UI.

**Стек:** Go 1.22+ (Fiber/Gin) · PostgreSQL 15+ · Redis · RabbitMQ · React 18 · Refine

**Назначение:** WMS, CRM, ERP, интеграции с маркетплейсами · мультитенантность · динамический роутинг `/api/data/{entity}`

> Репозиторий в подготовке

---

### 🛒 [svit_eCommerce](https://github.com/Maniforge/svit_eCommerce) — «Свит-Алтай»

Production-ready B2B/B2C e-commerce для оптовых и розничных продаж текстиля.

**Стек:** React 18 · Express · SQLite · JWT · WebSocket · Multer · Recharts · Expo (RN прототип)

**Внутри:** витрина · ЛК · админка с аналитикой · чат · лояльность · рефералы · 113 REST + WS
